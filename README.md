# sunset-valley
A **Stardew Valley** farming replica.  
Your grandpa have given you his **beloved farm** to take care for, but your excitement fades out as you discover that he is drowning in debt, and the farm is now on the line!  
Now you need to **grow crops**, and **collect your animals' produce** to **make profit** for **paying the debt** and **saving the farm** from the hands of **Mayor Wiles**!

### Controls:
Move: WASD  
interact: E  
Use: Left Mouse Button  
Clear tile: Right Mouse Button  
Advance dialogue: Space or Left Mouse Button  
Tools: 1, 2, 3, 4, 5  
Time: J, K, L  
Save: P  
Go to Menu: Escape  

## Built with
[Godot Game Engine v4.6.stable](https://godotengine.org)  
[Dialogue Manager plugin by Nathan Hoad](https://dialogue.nathanhoad.net)

## Contributing and expanding
If anyone wants to use my game as a template and further expand on it, then:
1. You will need to install **Godot Game Engine** (preferable to be v4.6.stable or a later version).
2. Clone the repo.
3. open the cloned repo folder using **Godot Game Engine**.
4. Start expanding on the project after you get the hang of how things work (sadly I didn't write any comments in the code).

## Why I built this project
I have been learning game development using Godot for about a year now, so I wanted to take the experience of developing a large scale project using new concepts and other things I learnt during developing the game.  
Also, I am obsessed with game dev ❤
